# LOOM design system

Warm editorial music studio: parchment/ivory field, oxblood and aubergine anchors, antique brass detail.

Display: Cormorant Garamond.
Functional: DM Sans.
Technical: IBM Plex Mono.

Motion is purposeful: slow orbital rings, moving waveform traces, active sequencer steps, and hover underlines. Respect `prefers-reduced-motion` by disabling non-essential motion.

Public navigation is narrative and exploratory. Authenticated navigation becomes dense because the studio itself is a tool, but the public site is not a dashboard.
