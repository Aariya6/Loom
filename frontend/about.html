under the floorboards

A music app with its workings left on the table.

LOOM is deliberately local-first: compositions are structured data, playback happens in the browser, and analysis is a Python service rather than a hosted model.

browser

TypeScript

Web Audio API · canvas visualisation · Indexed interaction.

service

FastAPI

Private sessions · validation · project persistence · analysis endpoint.

data

PostgreSQL / SQLite

User, session and composition data with ownership enforced at query time.

ml

Python

PCA, feature extraction and a path for heavier local neural models.

composition → tracks → notes → timing / velocity / instrument
                         ↓
                  descriptive analysis
                         ↓
             density · pitch · novelty · PCA
                         ↓
                  human decision
security

Small system. Serious boundaries.

Argon2id passwords, server-side sessions, CSRF checks, private-by-owner queries, input limits, rate limits and secure cookie settings are part of the application rather than postscript.
